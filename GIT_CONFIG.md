# Git Repository Configuration & Guide

This document outlines the Git setup, remote repository details, ignore rules, and standard workflow commands for the **Online Vehicle Rental Management System**.

---

## 1. Remote Repository Details

- **Remote Name**: `origin`
- **Repository URL**: `https://github.com/dasapradeepkumar-max/online-vehicle-rental-management-system.git`
- **Default Branch**: `main`

---

## 2. Ignored Files & Folders (`.gitignore`)

The project configured `.gitignore` prevents tracking sensitive, environment-dependent, binary, or auto-generated files:

| Category | Patterns Ignored | Rationale |
| :--- | :--- | :--- |
| **Virtual Environment** | `.venv/`, `venv/`, `env/` | Local Python packages should be installed via `requirements.txt`. |
| **Secrets & Config** | `.env` | Environment secrets/keys must not be committed to public git. `.env.example` is committed as a template. |
| **Database** | `instance/*.db`, `*.sqlite3` | Local SQLite databases (`site.db`) contain transient testing data. |
| **Python Cache** | `__pycache__/`, `*.pyc` | Compiled bytecode auto-generated by Python. |
| **Logs & Test Files** | `*.log`, `output.log`, `test_output.txt` | Debug log files and output dumps. |
| **IDE Settings** | `.vscode/`, `.idea/` | Personal editor settings and caches. |

## 3. Git Workflow Commands

### Check Status & Branches
```bash
# Check current repository status
git status

# List local and remote branches
git branch -a
```

### Making Changes & Committing
```bash
# Stage modified or new files
git add .

# Create a descriptive commit
git commit -m "feat: your commit message"
```

### Pushing & Pulling Updates
```bash
# Push committed changes to remote main branch
git push origin main

# Pull latest changes from remote main branch
git pull origin main
```

## 4. Environment Setup Checklist

When cloning this repository on a new system:

1. Clone the repository:
   ```bash
   git clone https://github.com/dasapradeepkumar-max/online-vehicle-rental-management-system.git
   cd online-vehicle-rental-management-system
   ```
2. Create and activate a Python virtual environment:
   ```bash
   python -m venv .venv
   .\.venv\Scripts\activate  # Windows
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Setup environment configuration:
   ```bash
   copy .env.example .env
   ```
5. Run the application:
   ```bash
   python app.py
   ```
